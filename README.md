# Sales Performance Dashboard

This project was developed as part of the Data Analyst Internship Task 4. The objective was to design an interactive dashboard using Power BI/Tableau to analyze sales data and provide meaningful business insights. The dashboard includes important KPIs such as Total Sales, Total Profit, Total Orders, and Profit Margin, along with visualizations like sales trends, category-wise performance, regional analysis, and top-performing products.

Interactive filters and slicers were implemented to allow users to explore the data dynamically and gain deeper insights. The dashboard helps stakeholders monitor performance, identify trends, and make informed business decisions. Through this project, I gained practical experience in data visualization, dashboard design, KPI selection, and business analytics using modern BI tools.
